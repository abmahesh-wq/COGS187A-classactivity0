Personalized Interfaces

Last time, we saw that AI changes its design when it knows more about the user. Today, we take the next step: what happens when the interface itself adapts to each individual user?

Big question

If a system can know each user individually, should every user get a different interface?

Your group will explore how personalization changes information architecture, what data the system would need, and where personalization becomes uncomfortable or inappropriate.

Meet the users

Maya · Beginner

First-year student. Complete beginner. Uses only an iPhone. Mainly wants to meet people and feel comfortable joining.

Daniel · Experienced

Experienced photographer. Owns a mirrorless camera. Interested in advanced workshops, competitions, and showcasing work.

Sam · Returning member

Busy graduate student. Has attended before. Mainly wants to see upcoming events and RSVP quickly.

Part 1 · Design three personalized homepages

  1. Use the same university photography club as the previous activity.
  2. For each user, decide what they should see first, what should be de-emphasized, and what may not need to appear on the homepage at all.
  3. Focus on information hierarchy, not just colors or visual styling.
  4. Sketch the top section of the homepage for Maya, Daniel, and Sam.
Optional AI prompt:“You are designing the homepage of a university photography club. Here is everything we know about the current user: [PASTE USER PROFILE]. Decide what this person should see first, what should be de-emphasized, and what should not appear on the homepage. Explain your information hierarchy.”

Part 2 · What does the system need to know?

Useful information

List the user information that would help personalize the homepage. Examples: skill level, device, prior attendance, interests, availability, previous RSVPs.

How would the system know?

For each item, decide whether it comes from explicit user input, past behavior, account history, location, inferred behavior, or another source.

Part 3 · The personalization line

For each item below, decide whether you would allow the website to use it for personalization. Be ready to explain why.

Part 4 · Group discussion

  • When does personalization become more useful than one universal homepage?
  • At what point does personalization become “creepy”?
  • Should users know why their interface looks different?
  • Should users be able to turn personalization off?
  • If every user sees a different navigation structure, do we still have one information architecture?
  • Who should decide what information the system is allowed to infer?

Final takeaway

Traditional information architecture asks: How should we organize the website?

Personalized interfaces introduce a new question: What rules should determine how the website reorganizes itself for each user?
